Nhập mã từ đúng tài khoản

Mỗi trường có hướng dẫn nơi lấy. ID là mã công khai; token nhập ở Quản lý khóa sau khi lưu.

GA4 trình duyệt không cần OAuth. API báo cáo, chi phí và gửi từ máy chủ cần thêm bộ khóa/quyền riêng.

Tùy chọn đồng bộ & tiền tệ

Chu kỳ tối thiểu 15 phút. Báo cáo chi phí cần VND và múi giờ UTC+7 được hỗ trợ.

Lưu và xác minh theo từng lớp

  1. Lưu & kiểm tra: lưu kết nối rồi kiểm tra cấu hình và quyền đọc API hiện có.
  2. Quản lý khóa: nếu API báo thiếu token, nhập bộ khóa hoặc kết nối OAuth từ thẻ kết nối.
  3. Xác minh dữ liệu nhận: dùng Tag Assistant, GA4 Thời gian thực hoặc Meta Test Events. Kiểm tra đọc API không tự xác nhận sự kiện đã nhận.
