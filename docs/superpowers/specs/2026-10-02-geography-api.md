# Danh mục hành chính qua API
Dùng Province Open API v2 (sau sáp nhập 2025), không phải API cơ quan nhà nước. Python/FastAPI, Jinja2 và JS hiện hành. Admin chọn chi nhánh, checkbox tỉnh hoặc tất cả; đồng bộ một snapshot tỉnh và xã/phường qua server. Chỉ catalog.write + MFA được công bố danh mục. Không tạo giá hay khẳng định vùng phủ sóng. Client dùng database và tải xã/phường khi chọn tỉnh, không phụ thuộc API bên ngoài.
Nguồn HTTP cố định, timeout và giới hạn kích thước; kiểm tra mã trùng, cấu trúc, liên kết cha. Snapshot kèm ngày tải được đóng gói làm dự phòng, hiển thị rõ nguồn thực sự dùng. UUID ổn định theo mã v2. Import atomic, idempotent, không đổi chi nhánh/cha; không ghi đè chỉnh sửa thủ công hay khôi phục địa bàn đã ngừng. Giữ dữ liệu cũ, giá và lead. Danh mục hết xuất hiện không tự xóa. RLS/private/service_role, một audit cho mỗi batch, không thông tin khách.
